## ADDED Requirements

### Requirement: Import SHALL decompress gzip CSV inputs as a stream

The import command MUST process `.csv.gz` artifacts using streaming decompression and MUST NOT require full decompressed payload materialization before COPY begins.

#### Scenario: Large gzip artifact imports without full in-memory expansion

- **WHEN** import loads a large `events.csv.gz` artifact
- **THEN** decompression MUST occur incrementally while COPY is in progress
- **AND** import MUST NOT allocate memory proportional to full decompressed file size

### Requirement: Import SHALL keep bounded decompression buffers

The import command MUST use bounded buffers for gzip read/decompress/write operations so memory usage remains stable for very large files.

#### Scenario: Import processes multi-gigabyte compressed file with bounded memory

- **WHEN** import reads a multi-gigabyte `.csv.gz` file
- **THEN** import MUST read and forward data in bounded chunks
- **AND** peak memory MUST remain bounded by buffer sizing and COPY pipeline overhead

### Requirement: Streaming decompression SHALL preserve import compatibility

Streaming decompression MUST preserve existing import behavior for transaction boundaries, table load order, and CSV compatibility generated by export.

#### Scenario: Existing export artifacts continue to load successfully

- **WHEN** import processes `.csv.gz` artifacts produced by current export flows
- **THEN** loaded rows and target table outcomes MUST match current import semantics
- **AND** truncate-before-load behavior MUST remain unchanged

### Requirement: Import debug logs SHALL expose decompression phase boundaries

Import debug output MUST include clear markers for decompress stream start and completion per table/file to aid diagnosis of resource-related failures.

#### Scenario: Debug logging enabled during compressed import

- **WHEN** import runs with debug logging on compressed inputs
- **THEN** logs MUST contain decompression start markers and completion markers tied to target table/file context
